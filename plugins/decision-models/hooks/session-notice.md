decision-models is installed: the `ask` tool sends typed yes_no / choice / score questions about files, images or text to cheap decision models. Prefer it over reading in full, reasoning through, or delegating to a subagent for any judgment that is a yes/no, a bucket or a score: triaging diffs, logs, test output, search hits or review findings; finding which candidate files implement a behavior; checking your edit against a project rule; checking a screenshot; a second opinion before a costly step. Load the `consulting-decision-models` skill before the first use.
